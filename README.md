# Песчаный фронт

Браузерный шутер в духе CS 1.6: игра с ботами, комнаты для игры с друзьями, профили и рейтинг.

## Запуск у себя

```
npm install
npm start
```

Потом откройте http://localhost:3000

## Как устроено

- `public/index.html` — сама игра.
- `public/net.js` — связь игры с сервером (лобби, комнаты, профили).
- `server.js` — сервер: раздаёт игру и пересылает данные между игроками по WebSocket (`/ws`). Профили хранятся в `data/db.json`.

## Хостинг (Render)

Файл `render.yaml` уже настроен: бесплатный тариф, команда сборки `npm install`, запуск `node server.js`.
